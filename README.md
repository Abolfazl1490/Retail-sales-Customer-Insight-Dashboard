# Retail-sales-Customer-Insight-Dashboard
Interactive Power BI dashboard analyzing retail sales performance, customer behavior, product categories, and monthly sales trends.

Retail Sales & Customer Insights Dashboard

Project Overview

This project explores retail sales performance and customer purchasing behavior using Power BI. The interactive dashboard provides an overview of sales, transaction values, product category performance, customer demographics, and monthly sales trends.

The goal is to transform raw retail transaction data into clear, actionable business insights through data visualization and analysis.

Business Questions

This dashboard addresses the following questions:

1. What is the overall sales performance?

2. Which product category generates the highest sales?

3. How are sales distributed across product categories?

4. How do sales change over time?

5. Which age groups contribute the most sales and transactions?

6. How is sales revenue distributed between female and male customers?

7. What is the average transaction value?

8. How does transaction quantity relate to sales amount?


Key Insights

1. Electronics Leads Sales

Electronics generates approximately 157K in sales, accounting for around 34.4% of total sales and making it the highest-performing product category.

2. Balanced Product Category Mix

Sales are distributed relatively evenly across Electronics, Clothing, and Beauty. No single category accounts for a majority of total sales.

3. Nearly Equal Sales Contribution by Gender

Female customers contribute approximately 51.1% of sales, compared with 48.9% for male customers.

4. Average Transaction Value

The average transaction value is approximately 456 monetary units, providing a baseline for understanding customer spending per transaction.


5. Customer Age Group Analysis

The dashboard compares sales revenue and transaction counts across five age groups to identify differences in purchasing contribution and transaction activity.

Monthly highs and lows should be documented only after confirming the chronological order and completeness of the monthly data.

Data Preparation & Analysis

The project uses retail transaction fields such as transaction ID, date, customer demographics, product category, quantity, and transaction amount.

Data preparation and analysis include:

- Preparing date fields for monthly and yearly analysis

- Creating customer age groups

- Calculating total sales, transaction counts, and average transaction value

- Comparing sales across categories and customer segments

- Building interactive visualizations in Power BI

How to Explore the Project

1. Clone or download this repository.

2. Open the ".pbix" file using Power BI Desktop.

3. Interact with the slicers to explore different customer segments, product categories, and years.



Limitations

This analysis focuses on sales and transaction behavior. Profitability, costs, and profit margins are not evaluated because the dashboard's current dataset fields do not provide the necessary cost and profit information.
